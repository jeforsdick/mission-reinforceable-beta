# Resource Map telemetry interpretation

Resource Map telemetry is descriptive engagement and usage data. It records only
intentional access to the Resources tab and its sections. It can support summaries
such as Resources opened (yes/no), number of Resources opens, sections viewed,
number of section opens, and most frequently accessed section.

Resource Map telemetry must not be labeled or interpreted as fidelity, treatment
integrity, mastery, or compliance. It is not a phase-change variable or required
daily dose component. QA Preview events are marked `qa_mode = true` and must be
excluded from participant engagement summaries.
