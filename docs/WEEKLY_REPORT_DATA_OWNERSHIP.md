# Weekly report data ownership

The Weekly Teacher Report is administered entirely in Qualtrics. Mission: Reinforceable does not host its form, accept its responses, or store its response data. A future end-of-week email will link teachers directly to Qualtrics; this repository intentionally contains neither a Qualtrics URL nor weekly-email delivery work.

## Mission: Reinforceable data

Mission: Reinforceable owns Daily, Mystery, and Crisis practice; gameplay responses and Mission Scores; hints; Resource Map usage; and engagement/session telemetry.

## Qualtrics data

Qualtrics owns the Weekly Teacher Report, including weekly Mission: Reinforceable usability and acceptability questions, teacher-reported target behavior, teacher-reported replacement or desired behavior, and weekly contextual comments.

The coaching dashboard's Weekly Practice Snapshot remains a gameplay-only summary derived from completed game sessions. It does not contain or imply Qualtrics responses.
